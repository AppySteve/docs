<Update label="September 11, 2026" description="v1.13">

### New Features
- **Manage confirmation permissions from Settings** — A new Permissions tab lets you see and control which agent actions are set to "Allow always" vs. "Ask," and every organization now gets the platform's own Allow/Deny/Allow always confirmation prompt before an agent edits shared knowledge files.
- **Sharper, legible images with GPT Image 2** — A new image model built for crisp text, logos, diagrams, and transparent backgrounds is now available alongside the existing models.

### Improvements
- **See your paused schedules, not just the active ones** — A toggle on the Schedules page reveals recurring schedules that are currently paused, instead of having them silently disappear.

</Update>

<Update label="September 7, 2026" description="v1.12">

### New Features
- **GPT-6 Astra and Claude Fable 5.1 are now available as model choices** — Two new frontier models — GPT-6 Astra and Claude Fable 5.1 — are now available for your agents to use, giving you more options for balancing quality, speed, and cost.

### Improvements
- **Get help by email, not just chat** — You can now reach support by email in addition to chat, so you're not stuck waiting in a chat window to get help.
- **Presentations now include your images** — Generated presentations can now pull in your own images directly, instead of relying only on stock or AI-generated visuals.
- **Videos can now carry burned-in captions** — Generated and edited videos can now have captions burned directly into the footage, so they're viewable anywhere without relying on a separate subtitle track.

</Update>

<Update label="August 30, 2026" description="v1.11">

### New Features
- **Ask for help without leaving the conversation** — Type --support in any conversation with an agent (web, Slack, Teams, Telegram, or email) and our support team gets a case opened immediately with everything they need to jump in — no separate email or ticket required.

### Improvements
- **Safer edits to shared knowledge files** — When an agent is about to overwrite or delete a file in your organization's shared knowledge base, it now asks you to confirm first (in Slack and Teams), instead of silently proceeding or renaming around the conflict.
- **Better, more flexible AI video generation** — Video generation now supports Veo 3.1 and MiniMax H3, with more resolution options (up to 4K) and duration choices. Requests outside a model's limits are automatically adjusted to the closest supported option instead of failing.

</Update>

<Update label="August 21, 2026" description="v1.10">

### Improvements
- **Support link works again** — The "Contact Customer Support" button, shown after repeated automation failures, now correctly opens the support widget instead of landing on a broken page.
- **A warmer welcome in Microsoft Teams** — When Violet joins a Teams conversation, the intro is now a rich card matching the Slack onboarding experience, instead of plain text.
- **Reach Violet from anywhere in the app** — The "Message Violet" shortcut now lives at the top of the sidebar nav on every page, not just the dashboard.

</Update>

<Update label="August 15, 2026" description="v1.9">

### New Features
- **Connect your own integrations** — Don't see the tool you need in our integration list? Now you can connect any API we don't natively support — describe what you want to do, and it gets set up as a working connection with no wait for a deploy.

### Improvements
- **More QuickBooks records you can update** — Update customers, vendors, items, and accounts directly from your agent — no more workarounds or manual edits in QuickBooks itself.
- **Build sharper automation triggers** — Filters on integration triggers can now check nested fields and require multiple conditions to match on the very same item in a list (for example, "fire only when this specific custom field changes to this specific value"). Rules that used to be impossible to express are now just a filter.

### Integrations
- **Reflect** — Connect Reflect to create tasks, append daily notes, create notes and links, and pull your books and graphs — right from your agent.

</Update>

<Update label="August 10, 2026" description="v1.8">

### Improvements
- **Shared PDFs, audio, and Office files now render correctly on public share links** — PDFs, audio files, and Office documents (xlsx, docx, pptx) now display properly on public share links instead of showing "Failed to load PDF file."

### Integrations
- **QuickBooks, Salesforce, and Zoho Books connect in one click** — No more hunting for base URLs, auth URLs, or token endpoints — the connect flow fills in the standard values automatically.

</Update>

<Update label="July 31, 2026" description="v1.7">

### Improvements
- **OneDrive and SharePoint files work in Microsoft Teams** — Paste a OneDrive or SharePoint link in Teams, or pick a file from the file picker, and agents can see and work with it directly. No manual re-upload needed.
- **CC and BCC on agent-sent emails** — When an agent sends an email on your behalf, you can now ask it to CC or BCC additional recipients — including reply-to addressing.
- **Long tasks now continue without interruption** — When an agent runs out of context mid-task, it now hands the work off to a fresh session automatically and picks up exactly where it left off. Your task keeps running; you never see an error.
- **Clearer messages when integrations hit errors** — When a connected app returns an error, agents now show a plain, actionable explanation instead of raw error text — so they can self-correct or tell you exactly what went wrong.

</Update>

<Update label="June 4, 2026" description="v1.5">
  ### New Features

  * **Slack interactive messages** — Appy agents running in Slack can now send buttons, dropdowns, and other interactive controls directly in the conversation. Click a button and the agent picks up right where it left off — no need to retype your choice.
  * **Undo/redo in the chat input** — Cmd+Z and Cmd+Shift+Z now work in the task chat input, making it easier to fix a message before sending.
  * **File uploads in the task chat** — HTML, CSS, JS, and JSON files can now be attached directly in the chat input, so agents can read and work with your code files without any workarounds.
  * **Screenshot tool** — Agents can now capture full-page screenshots of any public URL and deliver them as files in their response. Useful for visual QA, design reviews, and web monitoring.
  * **Plan switching for credit-based accounts** — Credit subscribers can now upgrade or downgrade their plan directly from the billing page without going through a new checkout flow.
  * **Credit usage history on the billing page** — A paginated table on the billing page now shows credits consumed per execution — date, task name, who started it, and credits used.
  * **Integration setup during onboarding** — New users are now offered a curated integrations picker (Gmail, Slack, Notion, Linear, and more) immediately after signing up, before billing — so your first agent can hit the ground running.
  * **Credit breakdown on the dashboard** — The dashboard now shows your platform credits and reward credits separately, so you always know exactly what's available and where it came from.
  * **Agents page filters on mobile** — The activity and agents page filters no longer squish on small screens. They wrap cleanly below the title on mobile and stay inline on desktop.

  ### Improvements

  * **SEO metrics are more reliable** — The Moz SEO tool now returns partial results instead of failing entirely when one data source is unavailable.
  * **Connecting integrations from the app is now smoother** — The OAuth connect dialog on the integrations page no longer gets stuck on a spinner after you authenticate. Connections register immediately and the page updates without a manual refresh.
  * **Execution pauses gracefully on low credits** — Instead of failing mid-task when credits run out, agents now pause and notify you via your active channel (Slack, Teams, or Telegram). Resume by replying after topping up — work in progress is preserved.
  * **Agents see files attached to earlier Slack messages** — When you @mention Appy in an existing Slack thread, any files shared in that thread are now automatically available to the agent at the start of the task.
</Update>
