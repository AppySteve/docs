When an agent builds and publishes a website — a landing page, a microsite, a client-facing report — it shows up here. Websites is the gallery of everything your team has shipped publicly, with a live preview of each one.

<Frame>
  ![Websites gallery showing published sites with preview thumbnails](/images/websites-gallery.png)
</Frame>

## Where these sites come from

An agent publishes a site to your organization's public URL when a task calls for it — ask Violet to build a page and publish it, and it appears here once it's live. Each tile is a real, currently-live page, not a draft.

## Browsing the gallery

- **Live preview thumbnails** — Every tile shows a current screenshot of the actual published page.
- **Search** — Find a site by name.
- **Creator filter (admins only)** — Admins can filter the gallery to sites published for a specific person. Members see only their own by default, so this control isn't shown to them.
- **Copy URL** — Each tile has a copy-link button for the site's public address — hand it to a client without opening the page first.
- **Click through** — Click a tile's preview or title to open the live site in a new tab.

<Note>
  A published website is not the same thing as an [artifact share link](/your-ai-team/administration/artifacts#sharing-a-file-publicly). A share link publishes a single document — a report, a spreadsheet — for anyone to view. A website is a full page or site your agents built and published in its own right. If your agent produced a document you want to share, look in [Artifacts](/your-ai-team/administration/artifacts); if it built you a page, it's here.
</Note>
