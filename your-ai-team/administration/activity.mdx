Activity is your audit trail. Every task triggered by anyone on your team — through Slack, Teams, email, a schedule, or a webhook — appears here in real time. You can see what's running, what's done, and who asked for what.

<Frame>
  ![Activity feed showing task cards with status and source](/images/activity-feed.png)
</Frame>

## Reading the activity feed

Each card in the feed shows:

- **Who requested it** — The team member who triggered the task, with their name and email.
- **Task title** — A short description of what the agent was asked to do.
- **Which agents were involved** — Violet and any specialists she delegated to.
- **Status** — Current state of the task (see below).
- **Progress** — A completion bar shows how far along a running task is.
- **Source** — The channel the task came from (Slack, Teams, web, email, etc.), shown as an icon in the top-right corner of each card.

## Task statuses

| Status | Meaning |
| --- | --- |
| **Running** | The agent is actively working on the task right now. |
| **Done** | The task completed successfully. |
| **Error** | The task hit an error and didn't complete. |
| **Blocked** | The agent needs input from you before it can continue. |
| **Idle** | No sub-tasks have started yet. |

## Filtering activity

Use the filter tabs at the top to narrow by source:

| Filter | Shows |
| --- | --- |
| **All** | Every task across all channels |
| **Web** | Tasks started from the web platform |
| **Slack** | Tasks initiated from Slack (shown when Slack is connected) |
| **Teams** | Tasks initiated from Microsoft Teams (shown when Teams is connected) |
| **Email** | Tasks triggered by email |
| **Schedule** | Tasks run automatically on a schedule |
| **Webhook** | Tasks triggered by an external webhook |

**Only mine (admins only)** — Admins can toggle the feed down to just the tasks they personally started. Members already see only their own tasks, so this control isn't shown to them.

## Task detail view

<Frame>
  ![Full-screen coverflow view of a task with sub-agent carousel](/images/activity-coverflow.png)
</Frame>

Click any card to open the full-screen detail view. If the task involved delegation, you'll see a coverflow-style carousel — one slide per sub-agent Violet brought in, plus a slide for Violet herself. Each slide shows that agent's task list (or a summary, if there's nothing to list), the files it produced, and its status.

Above the carousel, a stats bar shows the task count and file count for the whole run.

<Tip>
  The task detail view is useful for reviewing what an agent actually did — especially for scheduled tasks that run without you prompting them.
</Tip>
